# Codigo fuente

Esta carpeta contiene funciones y modulos reutilizables del proyecto.

## Subcarpetas

- `data/`: carga, limpieza y transformacion.
- `features/`: ingenieria y seleccion de variables.
- `models/`: entrenamiento, evaluacion y utilidades de modelos.
- `visualization/`: funciones para graficas y reportes visuales.

Mover aqui el codigo que deje de ser experimental y quieras reutilizar fuera de los notebooks.
