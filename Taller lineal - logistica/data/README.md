# Datos

Esta carpeta almacena los datos utilizados en el taller.

## Subcarpetas

- `raw/`: datos originales sin modificar.
- `interim/`: datos intermedios generados durante limpieza o transformacion.
- `processed/`: datos finales listos para modelado.

## Recomendaciones

- No sobrescribir archivos en `raw/`.
- Documentar el origen de cada dataset en `docs/data_dictionary.md`.
- Mantener nombres de archivos claros y consistentes.
