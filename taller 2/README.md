# Taller 2

Este es el proyecto para el taller 2.

## Estructura del proyecto

- `data/`: Datos utilizados en el proyecto.
  - `raw/`: Datos originales, inmutables.
  - `processed/`: Datos limpios y procesados listos para el modelado.
- `docs/`: Documentación del proyecto.
- `notebooks/`: Jupyter notebooks para exploración y prototipado.
- `reports/`: Reportes generados, como HTML, PDF, LaTeX, etc.
  - `figures/`: Gráficos y figuras generadas.
- `src/`: Código fuente para uso en este proyecto.
  - `data/`: Scripts para la ingesta y manipulación de datos.
  - `features/`: Scripts para la construcción de características (feauture engineering).
  - `models/`: Scripts para el entrenamiento de modelos predictivos.
- `requirements.txt`: Archivo con las dependencias para reproducir el entorno.
